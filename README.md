Desafio de Phishing Educacional
Descrição
Este repositório contém a documentação de um pequeno projeto/desafio realizado com fins de estudo e aprendizado sobre técnicas de engenharia social e conscientização em segurança da informação.

O objetivo da atividade foi compreender como funcionam ataques de phishing em ambientes controlados de laboratório, analisando conceitos relacionados à captura de credenciais e aos riscos que usuários podem enfrentar ao acessar páginas fraudulentas.

Ambiente Utilizado
Durante o desenvolvimento deste desafio foram utilizados os seguintes recursos:

Sistema Operacional: Ubuntu Linux
Terminal Linux
Ferramenta: SEToolkit
Privilégios de execução: usuário root
Observação
Durante os testes realizados, não foi possível acessar corretamente a página do Facebook por meio da configuração utilizada no laboratório. Uma possível causa é que a versão do SEToolkit empregada no momento dos testes estava desatualizada, o que pode ter afetado a compatibilidade com o site ou com seus mecanismos atuais de segurança.

Evidências
Para fins de documentação, este repositório contém capturas de tela (prints) do terminal demonstrando a execução dos comandos e o ambiente de testes utilizado durante o desafio.

Aviso Legal
Este projeto foi realizado exclusivamente para fins educacionais, pesquisa e conscientização em segurança da informação. O conteúdo apresentado não deve ser utilizado para atividades não autorizadas, invasões, coleta indevida de credenciais ou qualquer ação que viole leis, termos de uso ou a privacidade de terceiros.
